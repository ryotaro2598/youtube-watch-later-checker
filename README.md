# YouTube Watch Later Checker

YouTube の「後で見る」再生リストを書き出した CSV から、再生不可の可能性がある動画を絞り込むための Python スクリプトです。

YouTube の oEmbed API で動画情報を取得できるかを確認し、全件の判定結果、再生不可候補、取得できた動画をそれぞれ CSV に出力します。

## できること

- YouTube Takeout などで取得した「後で見る」CSV を読み込む
- 動画 ID ごとに oEmbed の取得可否を確認する
- 再生不可の可能性がある動画を候補として別 CSV にまとめる
- 追加日時、動画 URL、タイトル、チャンネル名、HTTP ステータスを一覧化する

このスクリプトは確認候補を作るための補助ツールです。動画の再生や、YouTube 上の再生リストからの削除は行いません。API キーや YouTube へのログインは不要です。

## 必要なもの

- Python 3
- インターネット接続

外部ライブラリは使っていません。標準ライブラリだけで動きます。

## 使い方

1. このリポジトリを取得します。

```bash
git clone https://github.com/ryotaro2598/youtube-watch-later-checker.git
cd youtube-watch-later-checker
```

2. Google Takeout などで書き出した「後で見る」の動画一覧 CSV を用意します。エクスポート全体ではなく、以下の列を持つ CSV を指定してください。

入力 CSV はリポジトリの外に置くことを推奨します。UTF-8（BOM あり・なし）に対応しています。

CSV には、次のいずれかの動画 ID 列が必要です。

- `動画 ID`
- `video_id`
- `Video ID`
- `id`

追加日時は、次の列名がある場合に読み取られます。

- `再生リストの動画の作成タイムスタンプ`
- `added_at`
- `time`
- `created_at`

動画 ID 列には URL ではなく動画 ID を指定します。空の動画 ID の行は出力されません。重複 ID は行ごとに確認されます。追加日時の列がない場合、出力の `added_at` は空になります。

3. リポジトリのフォルダでスクリプトを実行します。

```bash
python3 check_youtube_watch_later.py "$HOME/Downloads/Watch later の動画.csv"
```

ファイル名・保存場所が異なる場合は、実際のパスに置き換えてください。空白や日本語を含むパスは引用符で囲みます。

1 件ごとにリクエストし、確認後に 0.2 秒待機します。通信タイムアウトは 1 リクエストあたり 15 秒です。自動再試行・途中再開はありません。出力は全件の確認が終わった後に書き込まれます。

## 出力ファイル

入力 CSV と同じフォルダに、次の 3 ファイルが作成されます。

| ファイル名 | 内容 |
| --- | --- |
| `watch_later_checked.csv` | 動画 ID が空でない全行の判定結果 |
| `watch_later_unavailable_candidates.csv` | 再生不可の可能性がある動画、または確認エラーになった動画 |
| `watch_later_available.csv` | oEmbed で情報を取得できた動画 |

**同じフォルダに同名の出力ファイルがある場合は上書きします。** 別の入力 CSV を続けて確認する場合は、入力を別フォルダに置くか、前回の出力を移動してください。入力ファイル自体にも下記の出力ファイル名を使わないでください。

出力は UTF-8（BOM 付き）で、列は次の順序です。

```text
video_id,added_at,watch_url,status,http_status,title,author_name,thumbnail_url,error
```

入力の全列をコピーするのではなく、動画 ID と追加日時、および取得結果を出力します。

## 判定ステータス

| status | 意味 |
| --- | --- |
| `available_by_oembed` | oEmbed で動画情報を取得できた |
| `unavailable_candidate` | HTTP エラー。401・403・404 のほか、429（リクエスト制限）や 500 番台も含む |
| `check_error` | HTTP エラー以外の例外。通信失敗・タイムアウト・JSON 解析失敗など |

## 判定の限界と確認方法

- `available_by_oembed` は動画情報を取得できたという意味です。自分のアカウント・地域・端末で再生できる保証はありません。
- `unavailable_candidate` は削除済み・非公開の確定ではありません。年齢制限・地域制限・埋め込み制限・一時的な障害・YouTube 側の仕様変更などの影響も考えられます。このスクリプトは理由を特定しません。
- 429 や 500 番台が多い場合は、結果を削除判断に使わず、時間を置いて再実行してください。再実行すると出力が上書きされます。
- 候補 CSV には `unavailable_candidate` と `check_error` の両方が含まれます。`http_status`・`error` を確認し、`watch_url` を普段利用するブラウザで開いて手動確認してください。
- 再生リストの整理・削除は、確認後に YouTube 上で手動で行ってください。

## データの取り扱い・公開時の注意

入力 CSV には再生リストの内容や追加日時などが含まれます。Takeout のほかのファイルには視聴履歴なども含まれ得るため、エクスポート一式を公開しないでください。出力 CSV の動画 ID・URL・タイトル・チャンネル名・追加日時からも、興味や利用状況が推測される可能性があります。

処理はローカルで行いますが、動画 ID を含む動画 URL を YouTube の oEmbed エンドポイントに送信します。入力 CSV 全体や追加日時を送る実装ではありません。YouTube への通信では接続元 IP などの通常の通信情報も伝わります。

- 入出力 CSV・Takeout の ZIP や展開フォルダはリポジトリの外に保管してください。
- `.gitignore` の `*.csv` は未追跡 CSV の通常の追加を防ぎますが、追跡済みファイル・強制追加・過去のコミットには効きません。ZIP・JSON・HTML・スクリーンショット等も対象外です。
- 公開前に `git status --short`、`git diff --cached`、`git ls-files` で公開対象を確認してください。Issue や実行ログの共有時も実データを伏せてください。
- 誤ってコミットした場合、ファイルを削除するだけでは過去の履歴から消えません。公開を止め、履歴・配布物等の削除要否を確認してください。既に取得されたコピーを回収できる保証はありません。
- コミットには作成者名・メールアドレスも記録されます。業務用アドレス等を公開したくない場合は、今後のコミットに GitHub の非公開用メールアドレスを設定してください。設定変更だけでは既存履歴は変わりません。
